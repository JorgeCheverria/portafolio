# **App Name**: Jorge Cheverria Portfolio

## Core Features:

- One-Page Layout: Single-page design for easy navigation and clear presentation of information.
- Sectioned Content: Display sections: Hero, About, Technologies, Experience, Projects, and Contact.
- Technology Icons: Display icons representing key technologies like JavaScript, TypeScript, Python, React, Node.js, AWS/GCP.
- Interactive Animations: Implement subtle animations for interactive elements using framer-motion.
- Project Structure: Next.js project structure, including pages/index.tsx, components/, public/, and README.md.
- Deployment Ready: Deployment-ready setup with instructions for installation and deployment to Vercel.

## Style Guidelines:

- Dark color scheme for the background (#121212) to create a modern and sophisticated feel.
- Primary color: Soft light blue (#ADD8E6) representing JavaScript and TypeScript. The color will hint at the color schemes of the languages but in a desaturated and brighter way to make it suitable for the overall palette.
- Accent color: Muted green (#90EE90), an analogous color which hints at the language Python and provides a subtle contrast.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text to provide a balance of modernity and readability.
- Use react-icons for consistent and visually appealing icons representing various technologies and links.
- Responsive design using Tailwind CSS to ensure the portfolio looks great on all devices.
- Implement subtle fade-in effects and hover animations to enhance user experience.
